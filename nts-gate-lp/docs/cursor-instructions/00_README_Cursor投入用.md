## 🎯 改修の目的（背景）

1. **緊急: 視認性問題**
   `/subsidies/lp` でテキストが暗色背景に対して暗色のまま配置され、読めない状態。
   → `01` と `02` で解消する。

2. **重要: ネーミング刷新**
   「補助金活用ガイド」というタイトルが汎用的で、ライブラリの価値が伝わらない。
   → `01` の方針に従い `補助金別アクションガイド` 等へ刷新。

3. **本丸: LPクオリティ引き上げ**
   現状の自動生成LPは「制度概要ページ」止まり。
   → `04` の9セクション構成と `03` のトークンを使って、profits-ops.com 同等品質に引き上げる。

## ⚠️ 共通ルール（Cursor へ毎回伝える）

1. **コードを推測で書かない**
   既存のコンポーネント構造・ルーティング・データフローを必ず確認してから着手。
2. **既存の変数名・コンポーネント名を尊重**
   勝手にリネームしない。
3. **マイクロインタラクションは最後**
   構造とタイポ・カラーを正しく整えてから動きを足す。
4. **アクセシビリティはmust**
   コントラスト・focus-visible・キーボード操作・reduced-motion すべて必須。
5. **削除する前に確認**
   既存ページや他のセクションで参照されているCSSクラス・コンポーネントを削除しない。
