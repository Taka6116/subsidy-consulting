# 03｜デザイントークン定義（補助金LP用）

## 目的
profits-ops.com のデザインフィロソフィ（structured / tokenized / content-first / オフセット影 / グリーン×インディゴアクセント）を**補助金LPのトーン**に翻訳した、実装用デザイントークン定義。
本ファイルはCSS変数 / Tailwind theme.extend / shadcn/ui トークンのいずれにもマッピング可能。

## 6. モーション

| トークン | 値 | 用途 |
|---|---|---|
| `--motion.duration.instant` | 120ms | クリックフィードバック |
| `--motion.duration.fast` | 200ms | hover基本 |
| `--motion.duration.normal` | 320ms | カード浮遊 |
| `--motion.duration.slow` | 600ms | スクロールフェード |
| `--motion.duration.count` | 1400ms | 数値カウントアップ |
| `--motion.ease.out` | `cubic-bezier(0.22, 1, 0.36, 1)` | 標準 |
| `--motion.ease.in-out` | `cubic-bezier(0.65, 0, 0.35, 1)` | 強調 |

`prefers-reduced-motion: reduce` を必ずサポートし、上記すべてを`0ms`にフォールバックすること（必須）。

## 9. アクセシビリティ要件（必須）

- **コントラスト比**: 通常テキストは4.5:1以上、大文字（18pt以上）は3:1以上
- **フォーカスリング**: 全インタラクティブ要素に `outline: 2px solid #7DD3FC; outline-offset: 2px;` を適用（`:focus-visible` のみ）
- **タッチターゲット**: 最低 `44 × 44px`
- **`prefers-reduced-motion`**: 全アニメーションが停止できること
- **`prefers-color-scheme`**: 当面ダーク基調固定で良いが、ライトセクションのコントラストは別途担保

## 10. 実装例（Tailwind theme.extend）

```js
// tailwind.config.ts
export default {
  theme: {
    extend: {
      colors: {
        bg: {
          base: '#0B1729',
          elevated: '#13223D',
          light: '#F7F9FC',
        },
        accent: {
          primary: '#0EA5A4',
          'primary-strong': '#0D9488',
          secondary: '#FB923C',
          cyan: '#7DD3FC',
        },
      },
      borderRadius: {
        lg: '16px',
        xl: '20px',
        '2xl': '24px',
      },
      boxShadow: {
        offset: '5px 5px 0 0 rgba(0,0,0,0.05)',
        'glow-teal': '0 0 24px rgba(14,165,164,0.35)',
      },
      fontFamily: {
        primary: ['Zen Kaku Gothic New', 'ヒラギノ角ゴ ProN W3', 'Meiryo', 'sans-serif'],
        numeric: ['Inter', 'SF Pro Display', 'system-ui', 'sans-serif'],
      },
    },
  },
};
```

## 11. アンチパターン（やってはいけない）

- 生のhex値を component に直書き（必ずトークン経由）
- `!important` の濫用
- ホバー専用CSSのみ（`:focus-visible` を伴わない）
- アニメーションが`prefers-reduced-motion` を無視
- フォントサイズが上記スケール外（`13.7px` など）
- 透明度のついた色を不透明色として使う（背景が透けて読めなくなる）
