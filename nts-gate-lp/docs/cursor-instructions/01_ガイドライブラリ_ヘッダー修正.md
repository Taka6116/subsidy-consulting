# 01｜補助金活用ガイド ライブラリ ヘッダー修正指示書

## 目的
`/subsidies/lp` ページ上部「ACTION GUIDE LIBRARY / 補助金活用ガイド」セクションについて、ダーク背景に対するテキストの可読性を確保し、ネーミングを「ガイドの中身が伝わる」ものへ刷新する。

## 対象ページ / 対象セクション
- ルート: `/subsidies/lp`
- 対象: ページ最上部のヒーロー直下「ACTION GUIDE LIBRARY」見出しブロック
- 対象要素:
  - 英語キャッチ: `ACTION GUIDE LIBRARY`
  - 日本語タイトル: `補助金活用ガイド`
  - リード文: 「補助金ごとに、使える企業のイメージ・申請の流れ・相談前に見るべきポイントをLP形式で整理しています。」
  - メタタグ群: `公開中 N件` / `相談導線つきLP` / `自動生成・随時追加`

## 課題（現状）
1. ダークネイビー背景に対し、日本語タイトル「補助金活用ガイド」のテキストカラーがダーク寄りで、ほぼ読めない状態。
2. 「補助金活用ガイド」というネーミングが汎用的で、ライブラリの価値（制度ごとのアクション設計が見える）を表現できていない。

## 変更方針

### A. テキストカラーの修正（必須・全要素）

| 要素 | 現状 | 修正後 |
|---|---|---|
| 英語キャッチ `ACTION GUIDE LIBRARY` | アクセントカラー（薄シアン想定） | 維持（読めていればOK） |
| 日本語タイトル `補助金活用ガイド` | 暗色 → 不可視 | **`#FFFFFF`** / `font-weight: 700` |
| リード文 | 暗色 | **`rgba(255, 255, 255, 0.78)`** で階層を作る |
| メタタグ（公開中N件 等） | 既存のチップ色 | **背景: `rgba(255,255,255,0.08)` / 文字: `#FFFFFF`** に統一 |

**実装ルール**
- ハードコードされた `#000` / `text-slate-800` 等が残っている場合は必ず置換すること。
- Tailwindであれば `text-white` / `text-white/80` / `text-white/60` の3階層で揃える。
- 既存のダークモード対応クラスがある場合はそのまま活かしつつ、ライトモードでもダーク背景が前提なので無条件で白系を当てる。

### B. ネーミング刷新（必須）

**採用案: `補助金別アクションガイド`**

理由:
- 既存の英語表記 `ACTION GUIDE LIBRARY` と日本語が一致し、ブランディングの整合性が取れる
- 「制度ごとに違う使い方を案内している」というLPライブラリの本質を一語で伝えられる
- 「ガイド」だけだと汎用ヘルプに見えるが、「アクションガイド」とすることで"次に何をすればいいか分かる"が伝わる

**サブテキスト（H1直下のリード）も以下に差し替え**:

> 制度ごとに、対象企業のイメージ・申請の流れ・相談前に確認すべきポイントを1ページで整理。
> あなたの会社が使える補助金を最短で見つけられます。

### C. 予備案（クライアント判断で差し替え可能）

| 案 | ニュアンス | 推奨用途 |
|---|---|---|
| 補助金別アクションガイド | 一貫性・専門性 | **第一推奨** |
| 制度別 申請ナビゲーション | 機能寄り | 行政寄りの硬めトーン |
| 補助金の使い方ガイド | やわらかい | BtoC寄りの場合 |
| 申請までの道筋を、一枚で | コピー寄り | キャッチで使うなら |

## アクセプタンス基準（実装後チェック）
- [ ] PCのダーク背景下で、日本語タイトルが瞬時に読める（コントラスト比 4.5:1 以上）
- [ ] リード文がタイトルより一段階控えめなトーンで階層が成立している
- [ ] メタタグが3つ並列で、いずれも視認可能
- [ ] H1テキストが `補助金別アクションガイド`（または採用された別案）に変更されている
- [ ] モバイル幅375pxで折り返しが破綻しない
- [ ] Lighthouse Accessibility スコアが既存値以下に下がっていない

## 注意
- ヒーロー部の他要素（ロゴ、グローバルナビ、CTAボタン）には**触らない**。
- ガイドカード本体のスタイルは別指示書（02）で扱うため、このファイルではヘッダーブロックのみ修正。
