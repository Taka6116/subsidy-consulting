# 02｜ガイドカード（一覧）の視認性・階層修正指示書

## 目的
`/subsidies/lp` ページ下半分の「ACTION GUIDE カード一覧」について、ダーク背景下で各カード内テキストが読めない問題を解消し、情報階層を整える。

## 対象ページ / 対象セクション
- ルート: `/subsidies/lp`
- 対象: 補助金活用ガイド一覧のカード群（1枚〜N枚で繰り返し表示される領域）
- カード内の構成要素:
  1. 上部タグ: `ACTION GUIDE`
  2. タイトル: 例 `[第六回以降] 事業再構築補助金（共同申請者）`
  3. 説明文: 例 `新しい事業への挑戦を、資金面から前に進めるための制度です`
  4. メタ情報行: `補助上限：最大150,000,000円` / `公募期限：2026年10月12日`
  5. 公開日（カード右下）: `2026.4.27`
  6. CTA: `ガイドを見る →`

## 課題（現状）
- カード背景がダークネイビー寄りなのに、タイトル文字色が暗色のままで**ほぼ視認不可**。
- 説明文・メタ情報の階層差がなく、どこを読めばいいか分かりにくい。
- ホバー時のフィードバックがない、または弱い。

## 変更方針

### A. カード本体のスタイル

```
背景:        rgba(15, 24, 42, 0.6)  または既存のダーク色
枠線:        1px solid rgba(255, 255, 255, 0.08)
角丸:        16px（radius.xl）
パディング:  24px（モバイル）/ 32px（タブレット以上）
影:          0 4px 16px rgba(0, 0, 0, 0.25)
hover:       border 色を rgba(255, 255, 255, 0.18) に / translateY(-2px) / 影を 0 8px 24px rgba(0,0,0,0.35) に
transition:  all 240ms ease-out
```

### B. カード内テキストの色階層（必須）

| 要素 | カラー | サイズ / 太さ | 備考 |
|---|---|---|---|
| ACTION GUIDE タグ | `rgba(125, 211, 252, 0.9)`（薄シアン） | 11px / 600 / letter-spacing 0.08em / uppercase | 既存のままでもOK |
| タイトル | **`#FFFFFF`** | 18〜20px / **700** / line-height 1.5 | **最重要修正点** |
| 説明文 | `rgba(255, 255, 255, 0.7)` | 14px / 400 / line-height 1.7 | |
| メタラベル（補助上限/公募期限） | `rgba(255, 255, 255, 0.5)` | 11px / 500 / uppercase | |
| メタ値（金額/日付） | `#FFFFFF` | 14px / 600 | 数字部分はやや大きめでも可 |
| 公開日 | `rgba(255, 255, 255, 0.4)` | 11px / 400 | カード右下に配置 |
| CTA `ガイドを見る →` | `#7DD3FC` または `#FB923C`（オレンジ） | 14px / 600 | hover で下線 + 矢印が右に4pxスライド |

### C. メタ情報のレイアウト改善

現状の「補助上限：最大150,000,000円 / 公募期限：2026年10月12日」を、**2列のミニKPIカード**に変える:

```
┌────────────────┐ ┌────────────────┐
│ 補助上限         │ │ 公募期限         │
│ 最大1.5億円      │ │ 2026.10.12       │
└────────────────┘ └────────────────┘
```

- 各ミニカード: `background: rgba(255,255,255,0.04)` / `radius: 10px` / `padding: 12px`
- ラベルは小さく薄く、値を主役に。
- 金額表記は `150,000,000円` ではなく **`最大1.5億円`** に短縮（読み取り速度向上）。

### D. CTA `ガイドを見る →`

- カード全体をクリッカブルにする（`<Link>` でカードラップ）
- 視覚上の CTA はカード下端、左寄せ
- hover時:
  - 矢印が右に `translateX(4px)`
  - テキストに下線 (`text-decoration: underline; text-underline-offset: 4px`)

### E. グリッドレイアウト

| ブレークポイント | 列数 | gap |
|---|---|---|
| ~ 640px | 1 | 16px |
| 641 ~ 1024px | 2 | 20px |
| 1025px ~ | 3 | 24px |

カードの最小高さは揃える（`align-items: stretch`）。

## アクセプタンス基準
- [ ] タイトル「[第六回以降] 事業再構築補助金（共同申請者）」がカード内で第一に視線を引く位置・色になっている
- [ ] 説明文・メタラベル・メタ値の3階層が色で識別できる
- [ ] hover時にカードが浮き、CTA矢印が動く
- [ ] カード全体がクリッカブルでアクセシブル（`role`/`aria` 適正）
- [ ] スクリーンリーダーで「補助上限 最大1.5億円 公募期限 2026年10月12日」と自然に読まれる
- [ ] ダーク背景下でコントラスト比 4.5:1 以上（タイトルは7:1推奨）

## 注意
- ヘッダー領域（`ACTION GUIDE LIBRARY` 〜 メタタグ）は **01_** の指示書で扱うため、このファイルではカード本体のみ修正。
- 03_LP本体構成 で書く"自動生成LP本体"とは別物（カードはあくまで一覧サムネイル）。
